# Machine Learning Projects

This repository contains **three machine learning projects**, each organized in its own folder with all necessary files.

---

## Projects

### 1. ASL Detection (`asl_detection_project`)
A project to detect American Sign Language gestures from images.  
Includes notebooks, trained models, and project report.

### 2. Fraud Detection (`fraud_detection_project`)
A project to detect fraudulent transactions using machine learning.  
Includes model files, test scripts, and project report.

### 3. Heart Disease Prediction (`heart_disease_project`)
A project to predict the likelihood of heart disease based on patient data.  
Includes dataset, trained model, notebook, and project report.

---

## Usage
- Open the notebooks in Jupyter or run the Python scripts to test models.  
- Ensure necessary Python libraries like `numpy`, `pandas`, `scikit-learn`, `keras/tensorflow` are installed.
