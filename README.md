# Machine Learning Internship Projects

This repository contains machine learning projects completed during my internship experience. Each project is organized in its own folder with datasets, notebooks, trained models, and supporting files.

---

## Projects Included

### 1. ASL Detection
A machine learning and computer vision project focused on detecting American Sign Language (ASL) gestures from images.

#### Features
- Image-based gesture recognition
- Model training and evaluation
- Dataset preprocessing
- Trained model files included

#### Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- OpenCV

---

### 2. Fraud Detection System
A machine learning classification project designed to identify fraudulent financial transactions.

#### Features
- Fraud transaction prediction
- Classification modeling
- Data preprocessing and analysis
- Model evaluation

#### Technologies Used
- Python
- Pandas
- Scikit-learn
- NumPy
